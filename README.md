# Rahim Ahmed — Portfolio

A modern, MERN-focused developer portfolio built with **React + Vite + Tailwind CSS**.

## 🚀 Live Demo

🔗 [View Live](https://rahim-portfolio.netlify.app)

## ✨ Features

- 🎨 Neon green + Matrix rain dark theme
- 💼 Glassmorphism UI (Apple-inspired)
- 🤖 Custom AI chatbot (no API — pure JS knowledge base)
- 📱 Fully responsive (mobile-first)
- ⚡ Framer Motion animations
- 📬 Netlify Forms contact

## 🛠 Tech Stack

React · Vite · Tailwind CSS · Framer Motion · React Icons

## 🏃 Run Locally

```bash
npm install
npm run dev
```
